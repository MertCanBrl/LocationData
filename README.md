With this application, you can type any word you want and find all the places near you that contain that word via "google maps".

1. Save your code to a file:
    For example, as friendly_place_finder.py.

2. Install PyInstaller:
    Type this in your command prompt:

      pip install pyinstaller


3. Create the .exe file:
    Still in the command prompt, type:

      pyinstaller --onefile --noconsole friendly_place_finder.py


4. Open the generated file:
    In the dist folder, you will find your .exe file.
    Double-click it to run your app directly.
